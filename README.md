# Project Description

This project contains a TypeScript function called `emailChecker` that validates an email address.

The function verifies that the email:

- It contains at least one @.
- It contains at least one period in the domain name (but not the last character).
- It contains no spaces.
- It contains text before and after the @

The function returns `true` if the email is valid, and `false` otherwise.
